# TG 文件处理机器人（TXT File Bot）

一个基于 **Python + aiogram 3** 的 Telegram 机器人：按钮式操作界面，全部功能需兑换卡密后使用（纯卡密制会员系统）。可部署到 **Railway**。

## 功能一览



| 功能                | 说明                                                                                                                                      |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 📄 文件切割           | 按行数切割 TXT；切割后可选「插入手机号」：先输入每份要插多少个，再从你发的号码池随机抽取、插入每份文件的随机行（每份文件固定插入指定数量；号码不够时自动循环复用），最后发送「插入报告.txt」告知每个号码插入的文件与行号。文件每 10 个一批一起发送，不足 10 个全部一起发送                                |
| 🗜️ 解压 Zip 提取 TXT | 上传 ZIP，自动提取其中全部 TXT（含防路径穿越安全检查），按批返回                                                                                                    |
| ✏️ 批量重命名          | 多选 TXT 上传，输入前缀后统一重命名为「前缀\_1.txt、前缀\_2.txt…」                                                                                             |
| 📇 号码转 VCF        | 号码列表（一行一个）转为 VCF 通讯录文件                                                                                                                  |
| 🔄 号码去重           | 按纯数字去重（自动忽略空格 / 横杠 / 括号），保留首次出现的号码，返回去重结果与统计                                                                                            |
| 📚 合并文本           | 多个 TXT 合并为一个，导出文件名可自定义（默认 合并结果.txt）                                                                                        |
| 🔀 定制分包           | 批量上传多个 TXT，自动识别每行内字段（手机号 / 银行卡 / 身份证 / 金额 / 时间 / 名字），行间顺序不一致也能逐行识别，按你指定的顺序统一调换每一行的字段位置，输出保持原文件名；名字与号码粘连（如 刘玲 500240198612311624）会自动拆开识别 |
| 📊 xlsx 转 txt       | 批量上传 XLSX，逐行转成制表符分隔的 TXT；单元格内容原样保留（数字不变科学计数法、不四舍五入），只转第一个工作表，输出 TXT 与原文件同名 |
| 🎫 会员中心           | 查看会员状态、兑换卡密（纯卡密制，无免费试用）                                                                                                                 |
| 🔧 管理面板           | 管理员可见：生成 / 删除卡密、查看未使用卡密、卡密统计、成员列表、添加 / 扣除用户天数、全站广播、洗数据定价、洗数据用量统计、掉落记录、绑定掉落通知群、掉落通知模板；仅总管理员可见：洗数据价格下限、累计洗数据配额、管理员管理 |
| 📩 到账通知           | 管理员「添加会员天数」「洗数据加余额」时会自动私聊通知用户本人（含到账天数/金额与当前剩余），扣减操作不通知；用户屏蔽机器人则静默跳过 |

## 隐藏掉落（会员天数彩蛋）

- 使用**洗数据以外的功能**（文件切割、解压、重命名、VCF、去重、提取、加区号、分类、空号检测、合并、催收分包、Excel转txt）成功完成时，有 **1%** 概率掉落 **1~20 天**会员（越大概率越小），不限制频率。
- 使用**洗数据**完成时，有 **5%** 概率掉落 **3~25 天**会员（越大概率越小），不限制频率。
- 掉落天数**直接累加到用户会员时长**，用户无感知。
- 管理员在管理面板可查看「掉落记录」（累计/今日统计 + 最近明细）。
- 掉落通知：把机器人拉进通知群，在群里发 <code>/bind_drop</code> 绑定；之后每次掉落自动发通知到该群。通知内容可在管理面板「掉落通知模板」自定义（占位符：<code>{user_id}</code> <code>{username}</code> <code>{feature}</code> <code>{days}</code> <code>{expires}</code>）。
- 管理面板按钮（含「掉落记录」「绑定掉落通知群」「掉落通知模板」）支持设置会员表情图标：管理面板 → 按钮图标设置，选对应按钮后直接发一个会员表情即可。

## 管理员与总管理员

* **总管理员**（`SUPER_ADMIN_IDS`）：拥有最高权限，在管理面板中额外有「洗数据价格下限」「累计洗数据配额」「管理员管理」，可动态添加 / 删除管理员（存数据库，重启不丢失）。
* **管理员**（`ADMIN_IDS` + 总管理员动态添加）：可使用管理面板全部常规功能（不含价格下限、累计配额、管理员管理）。
* **洗数据价格下限**：所有洗数据档位单价不得低于该下限；已有更低档位自动按下限计费。
* **累计洗数据配额**：统计累计已洗数据行数（含待处理任务），达到配额后不再接受新的洗数据任务；管理面板与洗数据菜单会实时显示已洗总量与剩余可洗量。

## 本地运行（调试）



```
# 1. 准备 Python 3.11+
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt

# 2. 配置环境变量
copy .env.example .env      # Windows
# cp .env.example .env      # macOS/Linux
# 编辑 .env：
#   BOT_TOKEN=你的BotToken        （@BotFather 创建）
#   ADMIN_IDS=你的数字ID          （@userinfobot 查询）

# 3. 启动（未配置 WEBHOOK_DOMAIN 时为长轮询模式）
python main.py
```

## 部署到 Railway（GitHub → Railway）



1. **创建 GitHub 仓库**：把本目录所有文件（含 `requirements.txt`、`Procfile`）推送到你的 GitHub 仓库。

2. **Railway 新建项目**：打开 [railway.app](https://railway.app) → New Project → Deploy from GitHub repo，选择刚推送的仓库。

3. **添加 Postgres**（强烈推荐，保证卡密 / 会员数据持久化）：

* New → Database → PostgreSQL 创建后，复制它的连接串（`postgres://...`）。

1. **配置环境变量**（Variables）：



| 变量               | 说明                                                              |
| ---------------- | --------------------------------------------------------------- |
| `BOT_TOKEN`      | 必填，@BotFather 获取                                                |
| `ADMIN_IDS`      | 管理员 ID（可用中文逗号或英文逗号分隔多个）                                      |
| `SUPER_ADMIN_IDS` | 总管理员 ID（最高权限：可增删管理员、调整洗数据价格下限与累计配额）                          |
| `DATABASE_URL`   | 填第 3 步的 Postgres 连接串                                            |
| `WEBHOOK_DOMAIN` | 必填，形如 `https://你的应用.up.railway.app`（Settings → Networking 里可看到） |
| `WEBHOOK_SECRET` | 可选，填一串随机字符更安全                                                   |



1. **重新部署**：Railway 会在环境变量变更后自动重新部署。打开 Deployments 日志看到 `Webhook 模式：...` 即成功。

2. **给机器人发&#x20;**`/start` 开始使用；管理员发 `/admin` 打开管理面板生成卡密。

> 说明：配置 
>
> `WEBHOOK_DOMAIN`
>
>  后自动走 Webhook 模式（推荐，更稳定）；不配置则走长轮询，也可以运行，但建议正式使用用 Webhook。
> 注意：默认使用内存 FSM，请保持单实例运行（Railway 默认即单实例）。如需多实例，请自行把 
>
> `MemoryStorage`
>
>  换成 Redis 存储。

## 使用说明（卡密会员制）



* 用户所有功能入口都需**会员有效**才能进入；未开通 / 已到期会提示去「会员中心」兑换卡密。

* 管理员在「管理面板 → 生成卡密」输入 `数量 天数`（例如 `10 30` 生成 10 个、每个 30 天的卡密），卡密格式 `XXXX-XXXX-XXXX`。

* 管理面板其他功能：删除卡密（输入卡密即可删）、成员列表（≤30 人直接展示，超过发文件）、添加 / 扣除天数（输入 `用户ID或用户名 天数`，如 `123456789 30` 或 `@zhangsan 15`）、全站广播（纯文本，发给所有使用过机器人的用户）。

* 用户「会员中心 → 兑换卡密」输入卡密，会员有效期累加，到期自动失效。

## 常见问题



* **重启后卡密 / 会员数据丢失？** 本地 SQLite 文件在 Railway 上会随容器重建丢失，务必配置 `DATABASE_URL` 指向 Postgres。

* **文件太大？** 可通过环境变量调整：`MAX_FILE_SIZE_MB`、`MAX_ZIP_SIZE_MB`、`MAX_PHONES`、`MAX_SPLIT_FILES`、`MAX_UPLOAD_FILES` 等，见 `.env.example`。

* **中文乱码？** 上传文件解码优先 UTF-8，自动回退 GBK；输出文件统一为 UTF-8。
